# Final-Project-Automata
My final project for this class

The goal of this project is to give, most importantly, the teacher an opportunity to punish his students for their misdeeds
while also allowing the students an opportunity to fight back. If the student loses, then a random punishment is selected.
There are three games to choose from when the teacher decides which game he wants to play with his student. There is a text file
containing every student in the class to make sure the one the teacher selects is in the class, or to randomly select a student if
That's what the teacher wants. 

There are 4 files, each with its own class and purpose.
